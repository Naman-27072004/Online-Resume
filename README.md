# 📄 Online Resume Website

This project is a **personal online resume website** built using **HTML** to showcase my education, skills, work experience, and certifications in a clean and structured format.  
It serves as a digital alternative to a traditional resume and is part of my web development capstone projects.

---

## 📌 Project Overview

The Online Resume Website provides a simple, accessible, and professional way to present personal and professional information on the web.  
It highlights my background, technical skills, projects, and certifications in a well-organized layout.

---

## ✨ Features

- 👤 Personal profile section with photo  
- 🎓 Education details  
- 💼 Work experience & capstone projects  
- 🛠️ Skills with proficiency levels  
- 📜 Certifications  
- 📬 Contact page link  
- 🌐 Lightweight and fast-loading  

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS** *(optional / extendable)*
- **Responsive Web Design (basic structure)*
